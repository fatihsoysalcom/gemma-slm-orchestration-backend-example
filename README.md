# Gemma SLM Orchestration Backend Example

This Python example demonstrates how a backend orchestrator can leverage multiple small language models (SLMs) like Gemma to handle complex tasks. It simulates sentiment analysis and topic extraction SLMs, showing how their outputs are combined to form a more intelligent and context-aware response, highlighting the power of backend orchestration for SLMs.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
